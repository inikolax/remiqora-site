# remiqora.com

The site of [Remiqora](https://github.com/inikolax/remiqora) (a local AI music studio, at `/` and `/ru/`) and
[Remiqora Video](https://github.com/inikolax/remiqora-video) (a local AI video studio, at `/video/` and `/ru/video/`).

The pages are built by a generator outside this repository and committed here as plain HTML; served by GitHub Pages.
Please report problems with the site in the issues of the product it is about.

`/.well-known/oauth-cimd` is Remiqora's Hugging Face OAuth client metadata: it must stay at this address.
